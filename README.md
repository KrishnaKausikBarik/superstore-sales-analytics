# Sales Performance Dashboard

## Project Overview
This repository contains a comprehensive Sales Dashboard built in Tableau. The dashboard provides an interactive, high-level overview of sales performance, profitability, and customer segmentation to help stakeholders make data-driven decisions.

## Key Features & Visualizations
The dashboard includes several interactive visualizations to track core business metrics:
*   **Customer Profit Distribution:** A histogram displaying the count of customers across different profit bins.
*   **Revenue by City:** A bar chart analyzing total revenue generated across various cities.
*   **Customer Sales Categorization:** A detailed text table classifying individual customer IDs by their higher sales status.
*   **Sales by Category:** A pie chart and a stacked bar chart breaking down total sales across Furniture, Office Supplies, and Technology.
*   **Segment Distribution:** A packed bubble chart illustrating the proportion of Consumer, Corporate, and Home Office segments.
*   **Profit vs. Sales Scatter:** A scatter plot mapping profitability against sales volume to identify high-value customer groups and potential outliers.

## Data Source
The dashboard utilizes a retail dataset (resembling the standard Superstore dataset), featuring dimensional data such as Customer ID, City, Segment, and Category, alongside measures like Sales, Profit, and Revenue.

## Tools Used
*   **Tableau:** Used for data visualization, dashboard creation, and interactive parameter filtering.
