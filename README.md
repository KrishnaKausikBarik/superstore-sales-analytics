# Sales Performance Dashboard

![Sales Dashboard Mockup](watermarked_img_10551266723808131197.png)

## Project Overview
This repository contains a focused view of a Sales Dashboard built in Tableau. The dashboard provides an interactive overview of sales performance and customer categorization to help stakeholders make data-driven decisions.

## Key Features & Visualizations
The dashboard view features the following specific visualizations to track core business metrics:
*   **Sales Breakdown by Category:** A stacked bar chart displaying sales figures across Furniture, Office Supplies, and Technology categories[cite: 5].
*   **High Sales Customer Status:** A text table classifying individual customer IDs (e.g., AD-12345, BZ-67890) by whether they are "In" or "Out" of higher sales brackets[cite: 5].
*   **Sales by Category:** A pie chart breaking down the percentage of sales across Technology (35.964%), Furniture (34.571%), and Office Supplies (29.465%)[cite: 5].

## Data Source
The dashboard utilizes a retail dataset featuring dimensional data such as Customer ID, Category, and Segment (Consumer, Corporate, Home Office), alongside high-volume sales measures[cite: 5]. 

## Tools Used
*   **Tableau:** Used for data visualization, dashboard creation, and interactive parameter filtering[cite: 5].

## How to View the Dashboard
1. Clone this repository to your local machine:
   `git clone https://github.com/KrishnaKausikBarik/superstore-sales-analytics.git`
2. Ensure you have [Tableau Desktop](https://www.tableau.com/products/desktop) or [Tableau Reader](https://www.tableau.com/products/reader) installed.
3. Open the `.twbx` (Tableau Packaged Workbook) file included in this repository.
